# TuneRig – PC-Optimierung

TuneRig findet, was deinen Windows-PC bremst, und behebt es – nur mit deiner Zustimmung.

## Download

**[TuneRig-Setup-1.0.1.exe herunterladen](https://raw.githubusercontent.com/mrcefrnd/tunerig/main/download/TuneRig-Setup-1.0.1.exe)**

Doppelklick, Zielordner bestätigen, fertig. Keine Administratorrechte für die Installation nötig.
Windows 10 und 11. Beim ersten Start warnt Windows SmartScreen, weil die Datei nicht digital
signiert ist: »Weitere Informationen« → »Trotzdem ausführen«.

## Updates

TuneRig sucht beim Start automatisch nach neuen Versionen (`latest.json` in diesem Repository)
und aktualisiert sich auf Wunsch selbst. Deine Einstellungen bleiben erhalten.

## Deinstallieren

Einstellungen → Apps → Installierte Apps → TuneRig → Deinstallieren.
